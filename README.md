# Quote desk (sample)

A sample project: a laser cutting shop's quote spreadsheet, rebuilt as a small web app.

**Open it:** https://hunghoni.github.io/quote-desk-sample/

| | |
|---|---|
| **Before** | `before/laser-quote-sheet.xlsx`: the shop's quote sheet. Prices, discounts and formulas are spread over two tabs. |
| **After** | `app/`: add parts, see the price change as you type, save numbered quotes, print a quote, and keep every price on one page. |

The app gives the same totals as the spreadsheet. Press **Fill in a sample** on the page to see a full quote.

Northgate Laser is a made-up shop and all prices are examples. Quotes and prices are saved in your own browser only; nothing is sent anywhere.

Plain HTML, CSS and JavaScript. No build step and no libraries.
